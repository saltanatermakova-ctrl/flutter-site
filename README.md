# Сайт на Flutter

Учебный сайт, сделанный на Flutter Web: главная, темы курса, форма обратной связи с проверкой полей.

**Сайт:** https://ТВОЙ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/

## Запуск локально
```
flutter create . --platforms=web,windows
flutter pub get
flutter run -d chrome
```

## Десктопная версия (Windows)
```
flutter build windows
```
